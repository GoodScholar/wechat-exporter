# Triage Labels

技能中的五个标准分流角色映射到以下 GitHub 标签：

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 需求完整，可由代理实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予处理 |

技能提到某个分流角色时，使用表中的对应标签。将来调整标签命名时更新本文件，避免产生重复含义的标签。
