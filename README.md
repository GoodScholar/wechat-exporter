# 留篇 · 公众号文章导出

在本机浏览器中粘贴微信公众号文章链接，或从 RSS 订阅源勾选文章，导出 Markdown、HTML、PDF 和图片。项目仓库：[GoodScholar/wechat-exporter](https://github.com/GoodScholar/wechat-exporter)。

## 安装与启动

需要 Node.js 22 或更高版本，以及 Playwright 支持的 Chromium。

```bash
git clone https://github.com/GoodScholar/wechat-exporter.git
cd wechat-exporter
npm ci
npm run setup:browser
npm start
```

打开 <http://127.0.0.1:4318>。后续启动只需 `npm start`。端口冲突时可运行 `PORT=4319 npm start`；如需使用已安装的 Chrome 或 Chromium，可将 `CHROME_PATH` 设置为其可执行文件路径。

## 工作方式

后端是仅监听 `127.0.0.1` 的 Node.js/Express 服务，负责文章抓取、格式转换、任务历史和本地归档；`public/` 中的静态前端通过本地 API 提交与查看任务。工具不需要 API Key，也不调用第三方导出服务。

1. 粘贴文章链接（每行一篇，也支持含链接的分享文本），每批最多 50 篇。
2. 选择 Markdown、HTML、PDF 中的一种或多种格式。保存目录默认为 `.data/exports/`，也可以输入绝对路径或 `~/` 开头的路径并保存；更改目录只影响后续新批次。
3. 点击「开始导出」，查看读取正文、图片下载数量、格式生成和打包进度。可以取消当前批次，已经完成的文件会保留，未完成项可以重试。
4. 在导出记录中下载单篇 ZIP，或打包下载已有成果。如果 PDF 等某种格式失败，其他成功格式仍可下载；重试失败格式会复用此前的正文和图片，不重复抓取。服务重启后也可以继续重试。
5. 保存位置旁可以复制目录路径，或在系统文件管理器中打开该批次的文件夹。点击下载会通过浏览器另存一份，其位置由浏览器设置或保存对话框决定。
6. 遇到微信访问验证时，点击「浏览器验证」，在打开的独立浏览器中自行完成验证并保持文章页面打开，然后回到工具重试。工具不会自动处理验证码，也不会读取日常浏览器的登录信息。

每篇 ZIP 可包含 `article.md`、`article.html`、`article.pdf`、下载成功的 `images/` 和 `metadata.json`；仅生成所选格式。新的归档按日期、文章标题和唯一后缀命名，历史文件仍可通过原记录访问。

`.data/` 保存任务历史、目录设置、格式重试所需的缓存和独立验证浏览器的 profile。导出包保存在默认 `.data/exports/` 或创建批次时选择的目录；修改设置不会移动旧文件。关闭服务和验证浏览器后删除 `.data/`，可以清除这些内部数据和默认目录下的导出文件，自定义目录内的已有文件需要另行清理。

同一批次会合并重复链接；已有完整导出且格式组合相同的文章会复用本地文件。这是本地归档缓存，不会检测原文更新。

## 从 RSS 导入文章

需要已有的公众号订阅服务，例如自行部署的 [we-mp-rss](https://github.com/rachelos/we-mp-rss) 或 [WechRss](https://github.com/johamwon/wechrss)。留篇通过标准 RSS 读取文章链接；订阅服务的安装、扫码登录和文章同步仍由该服务负责。

1. 切换到「RSS 导入」，填入文章订阅源地址，点击读取文章。支持 RSS 2.0、Atom，以及本机或局域网中的 HTTP/HTTPS 服务。
2. 按标题关键词、开始和结束日期筛选，勾选需要导出的文章。日期范围包含首尾两天，按浏览器本地日期计算；缺少日期的文章只在未设置日期范围时显示。
3. 选择格式和保存目录，点击「开始导出」。每批最多 50 篇，使用与粘贴链接相同的去重、缓存、重试和取消流程。

以 we-mp-rss 为例，可以使用 `http://127.0.0.1:8001/feed/all.xml` 或管理页面提供的单个公众号文章源。不要填写只列出公众号订阅的 `/rss` 目录页。请将该服务的 `RSS_LOCAL` 设置为 `false`（配置文件为 `rss.local: false`），使源内链接指向 `mp.weixin.qq.com` 原文；本地阅读页和其他站点链接会被跳过。地址和配置以你实际部署的版本为准，相关定义见其 [RSS 接口源码](https://github.com/rachelos/we-mp-rss/blob/main/apis/rss.py)。

只导入当前订阅源返回的文章，不会自动补齐历史文章或跟随分页。每次最多显示 500 篇，响应大小上限为 5 MiB；较大的全文源可减少条数或关闭全文输出。筛选后隐藏的文章会取消勾选，更换地址或重新读取会清除旧选择。源地址和预览列表仅保留在当前页面，不自动定时同步。

如果遇到登录页或 HTTP 401/403，请在订阅服务中处理访问授权。本工具不读取浏览器登录凭据，不支持地址中嵌入用户名密码；跨域重定向需要改填最终 RSS 地址。读取订阅源不会执行其中的 HTML，也不会自动访问封面、正文图片或站外阅读页。

## 支持范围与限制

- 支持 `mp.weixin.qq.com/s/短链接` 和含 `__biz`、`mid`、`idx`、`sn` 的长链接。
- 仅支持能访问到正文的图文文章。删除、付费受限、账号迁移、风控验证或特殊消息类型可能无法导出。
- 保留正文常见结构、表格、代码、链接和部分文字样式；HTML/PDF 采用阅读排版，不保证与微信原排版完全一致。
- 不导出音视频、评论、阅读量和互动组件；不直接获取公众号历史文章列表，可从已有 RSS 服务导入其提供的文章链接。
- 图片下载失败时会保留提示及资源地址；只下载微信常用图片域名的 JPEG、PNG、GIF、WebP，单张最多 15 MB、单篇最多 150 张，累计 60 MB 后停止后续图片下载。
- 文章顺序处理，两篇之间间隔 1.5 秒；请求超时或失败后需手动重试，避免连续自动请求。

## 测试

安装 Chromium 后运行：

```bash
npm test
```

测试覆盖链接校验、去重、正文清理、验证/删除/迁移页面识别、离线图片、PDF 生成、目录设置与旧文件兼容、部分格式失败后的重试、任务取消和持久化，以及 RSS 读取、筛选选择、浏览器提交与下载流程。自动化测试使用固定文章输入及本地 HTTP 订阅源；订阅服务的真实微信登录、历史文章覆盖范围和原文可访问性需另外实测。
